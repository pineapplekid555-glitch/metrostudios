About Metro Studios

We are a Roblox development group making roleplay and simulation games, each set somewhere specific.

Our first game, Westbrook County, is an emergency-services roleplay set in an American county. It is updated regularly, and it comes with extras for communities: custom liveries, private servers and a server API.

Next are two simulators set in Scotland. Project Alba is a vehicle simulator and Oath of Caledonia is a political simulator.

If you want to help build any of it, take a look at the team page.
